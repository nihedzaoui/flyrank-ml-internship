## 1. Project Overview

This repository contains my complete FlyRank ML Internship project, including the weekly machine-learning work, data and feature analysis, modeling, validation, action recommendations, research paper, documentation, and final capstone materials.

The project focuses on **Applied Search Intelligence: Google Search Ranking & Discoverability**, using anonymized search data to develop a data-driven workflow for identifying pages that may benefit from content refresh actions.
